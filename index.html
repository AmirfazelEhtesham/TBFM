درباره TBFM About TBFM

TBFM یک ابزار سبک و ساده برای ساخت فرم‌های گرافیکی با Python و Tkinter است. هدف آن ساده‌تر کردن ساخت رابط‌های گرافیکی بدون نیاز به نوشتن تمام کدهای فرم از ابتدا است.

TBFM is a lightweight tool for creating graphical forms with Python and Tkinter. Its goal is to make GUI form creation easier without having to write every part of the form from scratch.
