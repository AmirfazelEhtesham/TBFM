درباره TBFM About TBFM

همه ما با یک کامپیوتر کار کرده‌ایم و می‌دانیم برای اینکه سیستم‌عاملی مثل ویندوز به ما چیزی که درخواست کرده‌ایم را نشان بدهد، به‌صورت پنجره به ما نشان می‌دهد. این پنجره‌ها ممکن است هر چیزی را نشان بدهند؛ مثل داده، فرم، ابزار و...

حالا سوالی پیش می‌آید: چطور می‌توانیم این پنجره‌ها را بسازیم تا بتوانیم توی آن‌ها داده نمایش بدهیم؟ جواب زبان برنامه‌نویسی پایتون است! برای پایتون یک کتابخانه‌ای به نام Tkinter وجود دارد که برای همین کار ساخته شده است.

اما شاید شما دانش کدنویسی کافی برای ساختن این پنجره‌ها نداشته باشید. برای همین برنامه TBFM یا Tkinter Based Form Maker به کمک ما می‌آید! این برنامه ابزاری برای طراحی بصری فرم‌ها و رابط‌های گرافیکی با استفاده از Tkinter در پایتون است. با TBFM می‌توانید فرم خود را طراحی کرده و کد پایتون آن را ایجاد کنید. We have all worked with a computer, and we know that when an operating system such as Windows needs to show us something we requested, it displays it in a window. These windows can show almost anything, such as data, forms, tools, and more.

This raises a question: how can we create these windows so that we can display data inside them? The answer is Python! Python has a library called Tkinter that was created specifically for this purpose.

However, you may not have enough coding knowledge to build these windows yourself. That is where TBFM, or Tkinter Based Form Maker, comes in! TBFM is a tool for visually designing forms and graphical interfaces using Tkinter in Python. With TBFM, you can design your form and generate its Python code.

ساخت فرم‌ها بدون نیاز به نوشتن تمام کدها به صورت دستی. Create forms without manually writing all the code.

Py

پایتون Python

تولید کد پایتون برای فرم‌های ساخته‌شده با Tkinter. Generate Python code for your Tkinter forms.

باز کردن فایل‌های ساخته‌شده Open Created Files

فایل‌های ساخته‌شده را دوباره باز کرده و روی آن‌ها کار کنید. Reopen created files and continue working on them.

آموزش استفاده از TBFM How to Use TBFM

۱
فایل TBFM.py را اجرا کنید تا پنجره‌ی اصلی برنامه باز شود. Run TBFM.py to open the main window.
۲
اگر می‌خواهید فرم جدیدی بسازید، روی «ساخت پنجره جدید» بزنید، اندازه‌ی پنجره را انتخاب کنید و نام فایل پایتون را وارد کنید. اگر می‌خواهید فرمی که قبلاً ساخته‌اید را ویرایش کنید، روی «باز کردن پنجره جدید» بزنید و نام فایل موجود را وارد کنید. To build a new form, click "Make New Window", pick a window size, and enter a Python file name. To edit a form you already made, click "Open New Window" and enter the existing file's name.
۳
پس از باز شدن فرم، از منوی «جدید» می‌توانید متن‌باکس (TextBox)، لیبل (Label)، دکمه (Button) یا آیکون پنجره اضافه کنید. Once the form window opens, use the "New" menu to add a TextBox, Label, Button, or window icon.
۴
برای هر عنصر، ستون و ردیف مورد نظر را در پنجره‌ی کوچکی که باز می‌شود وارد کرده و روی «Continue» کلیک کنید تا عنصر روی فرم اضافه شود. For each element, enter the column and row in the small popup window and click "Continue" to add it to the form.
۵
هنگام ساخت دکمه، می‌توانید گزینه‌ی «Custom...» را فعال کنید و کد پایتونی که با کلیک روی دکمه اجرا می‌شود را خودتان بنویسید. When adding a Button, you can enable "Custom..." and write your own Python code to run when it's clicked.
۶
در پایان کار، از منوی File گزینه‌ی Save را انتخاب کنید تا فایل پایتون نهایی فرم شما ذخیره شود. When you're done, choose Save from the File menu to write out the final Python file for your form.
